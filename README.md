# Mi Portafolio Web

## Descripción

Este proyecto consiste en un portafolio web personal desarrollado para presentar información sobre mí, mis proyectos, los servicios que ofrezco y mis medios de contacto.

El sitio cuenta con una página principal y secciones adicionales para conocer más sobre mi perfil y mi trabajo. También incluye una sección de proyectos destacados para facilitar la navegación y mostrar mis trabajos.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- Bootstrap
- Sass
- SEO (optimización para motores de búsqueda)

## Estructura del proyecto

- `index.html`: página principal del portafolio.
- `pages/`: páginas adicionales del sitio.
- `styles/`: archivos de estilos CSS.
- `assets/`: imágenes y otros recursos del proyecto.

## Cómo visualizar el proyecto

**Opción 1: Desde GitHub**

Ingresá al repositorio y consultá los archivos del proyecto.

**Opción 2: Desde tu computadora**

1. Cloná el repositorio:

   ```bash
   git clone https://github.com/micaelarnavarro-afk/portafoliocss.git
   ```

2. Ingresá a la carpeta del proyecto:

   ```bash
   cd portafoliocss
   ```

3. Abrí el archivo `index.html` en tu navegador.

No es necesario instalar dependencias para visualizar la versión HTML y CSS del proyecto.

## Flujo de trabajo con Git y GitHub

Para organizar las modificaciones se utilizó el flujo de trabajo basado en ramas (*Feature Branching*).

- **Ramas:** se creó una rama independiente para desarrollar la mejora de la sección de proyectos destacados.
- **Commits:** se registraron los cambios realizados para mantener un historial de modificaciones.
- **Pull Requests:** se utilizó un Pull Request para proponer e integrar los cambios en la rama `main`.
- **Issues:** se pueden utilizar para registrar tareas, mejoras pendientes y posibles errores del proyecto.
